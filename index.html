Pick a range — downloads one Excel file with every still-open case due in that window, across all NBFCs (Monedo, Blacksoil, Fintree, Term Loan).



Manager reports — pick the NBFC and the report, tick the rows your manager wants highlighted, then download or copy a ready-to-send screenshot. Only open (unpaid) cases are included.

Upload one Excel/CSV file with as many columns as you have — Customer, NBFC, Invoice, Amount / Disb. Amt, O/S Principal, Due Date, Disbursement Date, ROI %, Previous Interest, Phone, VAN, Notes, Status. Missing columns are simply skipped. If an invoice number in the file already exists in the ledger, that entry is updated in place (not duplicated) — so you can re-upload the same file later with extra columns filled in and it will just fill in the gaps.

Upload a file with columns customer_name plus any of Phone / Email / Virtual Account Number (and optionally IFSC code / Beneficiary Name). Matches each customer already in the ledger by name and fills these in on every one of their invoices — handy for loading up call/email lists in bulk.

For lender files confirming actual repayment collections (columns like customer_name, amount, current_status, trigger_date/settlement_date, settlement_status) — e.g. Fintree's Term Loan settlement report. Only rows marked successful get counted. For Term Loan: this actually marks the EMI as paid and moves the schedule forward. For Monedo / Blacksoil / Fintree: it only logs to your Payment History and never touches that invoice's amount, status, or outstanding balance.
